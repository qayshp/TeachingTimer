# Companion and CI consistency review — November 12

## Corrected

- PR checks selected an older toolchain than release checks. Both now select
  Xcode 27.2 on xcode-27, with a CI contract test for runner, selection and strict
  real-runtime smoke. Two red checks represented one failure plus its aggregator.
- The captured watchOS 26.5 active-relaunch rejection remains #27, not a claimed
  runtime fix. A subsequent runtime-download failure exposed the missing explicit
  Xcode selection; that configuration is now matched too.
- Companion request/file metadata now correlates completion across retries.
  Old timeouts, responses and unsolicited/late files cannot finish a newer wait.
  The versioned request prevents an older Watch from silently ignoring a new
  requested window. It fails explicitly instead, with update/version guidance
  rather than an ineffective retry loop.
- Incoming and restored files are bounded and validated before email. Saved
  report age, window, event count and originating build are visible. Native Mail
  presentation holds one immutable attachment; expanded connection detail is
  secondary to the primary support actions. A compact introduction and separate
  saved-report section keep the request and email actions easier to find.
- README, support, tester guide, privacy, status, roadmap, changelog and packaging
  docs now describe the optional companion and distinguish current behavior from
  the historical Watch share-sheet experiment. The verified November 11 receipt
  is separate from unverified follow-up installation and general reliability.
- CI now compiles the iPhone Simulator app with its embedded Watch target, plus
  exercises real report output, queue failures, request correlation and bad files.

## Follow-up: page usability

The information pages were reviewed for task order, scrolling, scan targets and
support actions. Help was one long article, contact information lived under
About, and Watch report diagnostics added many rows to the primary flow.

- Help is now a short topic index. Music recovery comes first, followed by class
  timing, counts and session recovery. Contact support and report transfer live

- Settings has two adjacent toggles and one short footer. Privacy summarizes
  the important choices, with separate full-policy-on-Watch and phone routes.
  Long policy/license text remains a deliberate secondary read.
- Watch report preparation/sending stays prominent; full bounds, per-journal
